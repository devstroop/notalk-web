About NoTalk

A generic social engagement platform — not a WhatsApp client.

NoTalk is a headless platform for teams that run conversations at scale. It provides multi-account orchestration, a full REST API, an MCP server for AI agents, and per-account Copilot & Autopilot — without tying you to any single social network.

Principles

  • Generic, not single-platform. Built for WhatsApp today, extensible to any channel. The UI says “social engagement”, not a brand.
  • API-first. 64+ endpoints, scoped API keys, webhooks — everything the dashboard does is an API call.
  • Own your data. Self-hostable with one binary + one BFF. Billing is optional (billing.enabled=false).
  • Agent-ready. 26 MCP tools let Claude, Cursor, or any model send, search, and automate — with approvals.

What’s inside

Backend (notalk-server)

Go • whatsmeow • SQLite/Postgres • 64+ endpoints • webhooks • billing • roles & permissions

Frontend (notalk-web)

Hono + HTMX + Tailwind + Alpine • BFF proxies to Go • Cloudflare Workers-ready

MCP

26 tools: listChats, sendMessage, searchMessages, manage groups — for any MCP client

AI

Copilot (drafts with context) & Autopilot (rule-based auto-reply + escalation) — per account

Self-host

git clone https://github.com/devstroop/notalk-server && docker compose up
# frontend
git clone https://github.com/devstroop/notalk-web && npm install && npm run dev

Read notalk-server & notalk-web for full docs.
